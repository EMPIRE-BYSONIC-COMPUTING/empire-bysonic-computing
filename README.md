# Empire Bysonic Computing

A static website for Empire Bysonic Computing, a computer repair, maintenance, upgrade, quotation, and sales business serving the Southern Suburbs, Cape Town, Western Cape.

## Features

- Laptop and desktop repair information
- Hardware diagnostics and stress-testing services
- RAM and SSD upgrade information
- Screen, bezel, charging-port, and component repair services
- Repair booking and quotation pages
- Device sales listings with browser-based form storage
- SnapScan payment-link button
- Animated service and social-media buttons
- Local customer-support chatbot with prewritten responses
- Responsive layout for desktop and mobile screens
- SEO metadata and local-business structured data

## Main Files

- `index.html` - Published homepage
- `website.html` - Alternate full website page
- `style.css` - Shared styling and LED effects
- `chat-widget.js` and `chat-widget.css` - Free, browser-only support chatbot
- `Payment.html` - Payment and repair-service page
- `Intake Form.html` - Repair intake form
- `Hardware Repair & Quotation.html` - Hardware quotation page
- `Physical Diagnostics.html` - Diagnostic services page
- `Repairs & Maintenance.html` - Repairs and maintenance page
- `Modular Component Swops.html` - Component replacement page

- `sitemap.xml` - Search-engine sitemap
- `robots.txt` - Search-engine crawling instructions
- `images/` - Local website images

## Categorized Downloads

Add application software and related files to folders under `downloads/`, such
as `downloads/Applications/` or `downloads/Drivers/`. Both the homepage and
`downloads.html` group files by their first-level folder; files may also be
organized in nested folders within a category. Files placed directly in
`downloads/` appear under "Other Downloads".

Place operating system installation files under
`downloads/Operating Systems/`. The homepage's "OS Downloads" button and
`os-downloads.html` list files from that folder and exclude them from the
application software list. Existing Windows installation media in root-level
`boot/`, `efi/`, `sources/`, and `support/` folders is also treated as operating
system content for compatibility.

## GitHub Pages

The published homepage is:

`https://empire-bysonic-computing.github.io/empire-bysonic-computing/`

GitHub Pages uses `index.html` as the default homepage. When publishing changes, push at least:

- `index.html`
- `style.css`
- `sitemap.xml`
- `robots.txt`
- Any changed page or image files

`website.html` only needs to be pushed when that alternate page has also been changed or is being accessed directly.

## SnapScan Payment Link

The payment page contains a placeholder payment URL. Replace it in `Payment.html` with the real payment link created in the SnapScan merchant dashboard:

```javascript
const snapScanPaymentLink = 'YOUR_REAL_SNAPSCAN_PAYMENT_LINK';
```

The payment URL should be generated by the business owner through the SnapScan merchant account. Never place merchant passwords, secret keys, or private credentials in this repository.

## Run Locally

Because this is a static website, it can be opened directly in a browser by opening `index.html`. The support chatbot uses prewritten browser responses, so it needs no Node server, API key, Render account, or paid service.

For example, use the VS Code Live Server extension or any simple static-file server.
