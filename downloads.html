Software & Guides

Official driver support, Windows tools, and commonly used computer software.

For sound, Wi-Fi, Ethernet, Bluetooth, graphics, and touchpad drivers, start with the laptop manufacturer's support page and select the exact model and Windows version. A single driver installer cannot safely support every computer. The curated links go to vendor sources and do not copy vendor installers. Any separately listed repository-hosted files are published by this site and should only be shared when redistribution is permitted. Avoid third-party driver bundles and don't install drivers for a different model. For most devices, check Windows Update before manually installing drivers.

Depending on the device, drivers may also be needed for the chipset, webcam, card reader, storage, USB, or printer. BIOS and firmware updates are model-specific; use only the exact manufacturer's instructions. Find the computer model on its label or in Windows System Information (search for System Information from Start).
